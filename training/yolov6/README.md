# YOLOv6

The detector is trained with the training script from the official [YOLOv6 repository](https://github.com/meituan/YOLOv6). I reused [`tools/train.py`](https://github.com/meituan/YOLOv6/blob/main/tools/train.py) and only changed the dataset and config for dendrites.

## Citation

If you use our trained weights, please cite our paper.
